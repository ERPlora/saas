{% trans "We do not ask you: we do it ourselves" %}

{% blocktrans trimmed %} Because at eleven in the morning, with the place full, the honest answer to "do you want to update?" is no — and it should be. If we asked, the day the answer really mattered — a security fix, a change in the invoicing rules — the update would arrive late, or never. {% endblocktrans %}

{% blocktrans trimmed %} So we do not ask: we do it ourselves. Everyone runs the same current version, which is the only way we can fix something for one shop and have it fixed for all of them the same afternoon. {% endblocktrans %}

{% blocktrans trimmed %} If you want something sooner, there is an Update button in your hub — for the hub and for each module. You can bring it forward; the only thing you cannot do is leave it for another day. {% endblocktrans %}

{% blocktrans trimmed %} That decision is only fair if we carry the weight of it. These are the four things we owe you for not asking. {% endblocktrans %}

{% trans "When we do warn you" %}

{% blocktrans trimmed %} There is one case where a change deserves your attention even though nothing stops: when it touches the path you walk two hundred times a day and know by heart — signing in, taking the order, charging. A button that moves there is not an improvement, it is an interruption, even if the service never went down. {% endblocktrans %}

  • {% blocktrans trimmed %}If a change touches that path, we announce it inside the product before it arrives.{% endblocktrans %}
  • {% blocktrans trimmed %}If it does not — fixes, speed, colours, settings screens, new features — it simply arrives.{% endblocktrans %}

{% blocktrans trimmed %} We keep the bar there on purpose. If we announced everything, nobody would read anything, and the day we needed you to read, you would not. {% endblocktrans %}

{% trans "And if a change leaves you worse off" %}

{% blocktrans trimmed %} If one of those announced changes takes away something you were using, and it is not a trifle, you do not have to put up with it. We tell you by email before it lands, and from then you have thirty days to leave without paying anything: we give you back the part of the period you had paid for and not used. Your data leaves with you — you can export it. {% endblocktrans %}

{% blocktrans trimmed %} And if an update breaks something, that one is on us. We fix it. If we do not fix it, you pay less for the time it was broken, and you do not have to prove we did anything wrong. {% endblocktrans %}

{% trans "The app you install is different" %}

{% blocktrans trimmed %} The desktop and mobile app is a program on your own machine, not on our servers, so we never install it for you. We tell you there is a new version and you choose when. Your hub is ours to keep up to date; your computer is yours. {% endblocktrans %}
