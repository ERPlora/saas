# Use ERPlora on your devices

ERPlora is **Hub Cloud**: a web app you open in a browser, with its database hosted in the Cloud environment managed by ERPlora. There is nothing else to install to use the ERP. There is a single installable **ERPlora app** for desktop and Android — the same Hub, packaged — and it is what reaches point-of-sale hardware.

## Hub Cloud in a browser

Hub Cloud runs in a current desktop or mobile browser and requires an internet connection. Open the Hub URL supplied for your business and complete the sign-in flow described in **First access and navigation**.

For the best experience, keep the browser updated and allow the Hub to store site data. Private browsing and automatic site-data deletion can remove the trusted-device state.

## Install Hub Cloud as an app (PWA)

After login, ERPlora can offer a native-style installed view. This is the same Hub, but it opens from its own icon without normal browser bars.

- **Chrome or Edge:** use **Install app** from the address bar or browser menu.
- **Android:** use **Install app** or **Add to Home screen**.
- **iPhone or iPad:** open the browser's Share menu and choose **Add to Home Screen**.

Installing the PWA does not automatically trust the device. Device trust is created through the email sign-in flow.

## Hardware: the installed app

To print thermal receipts or open the cash drawer, install the **ERPlora app** on the machine that reaches the printer. There is no separate agent and nothing to pair: it is the same Hub, and it works over the local network. See [the ERPlora app](/app/) for the supported hardware.

## Using several devices

Hub Cloud supports several devices connected to the same Hub; trust each work device separately. They all share the same Hub database in the Cloud environment, so there is nothing to copy or synchronize between devices.

## Getting started

Don't have a Hub yet? On the [ways to try ERPlora page](/download/) you can **create a free cloud Hub** or **download the ERPlora app**. Both paths go through the free signup.
