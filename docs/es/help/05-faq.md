# Preguntas frecuentes

## Acceso

### ¿Por qué veo email y contraseña en vez del teclado PIN?

El acceso por PIN solo aparece en un dispositivo de confianza que tenga al menos un usuario del Hub con PIN. Entra con el email y la contraseña Cloud, activa **Confiar en este dispositivo** y crea el PIN de 4 dígitos cuando se solicite.

### ¿Existe un asistente de configuración después del login?

No. El dashboard muestra avisos concretos únicamente para apps instaladas que todavía necesitan configuración. La información global se gestiona en **Ajustes**.

### ¿Qué ocurre si borro los datos del navegador?

El dispositivo puede perder su estado de confianza y la presentación guardada de los usuarios. Vuelve a iniciar sesión con email y contraseña. El runtime sigue siendo la autoridad sobre qué usuarios del Hub existen.

## Productos y dispositivos

### ¿ERPlora necesita internet?

Sí. Hub Cloud es una aplicación web y necesita conexión a internet para funcionar.

### ¿Pueden varios dispositivos utilizar el mismo Hub?

Sí. Hub Cloud admite varios dispositivos conectados al mismo Hub; cada uno debe completar su propio flujo de confianza. Todos comparten la misma base de datos del Hub en el entorno Cloud.

### ¿Puedo instalar ERPlora como una aplicación?

Hub Cloud se abre en el navegador y puede instalarse como PWA desde un navegador compatible. Existe además una única **aplicación de ERPlora** instalable, para escritorio y Android —el mismo Hub, y la que llega a las impresoras de tickets y al cajón portamonedas—; consulta [Opciones para probar ERPlora](/download/).

## Apps

### ¿Dónde están las apps?

Usa el botón de cuadrícula de la barra superior o abre **Apps** para ver las apps del Hub y activar las que necesites.

### ¿Por qué no puedo activar o configurar una app?

Comprueba que tu rol local sea propietario o administrador, que la app esté incluida en el plan del Hub y que también puedan activarse las apps que necesita.

## Datos y soporte

### ¿Dónde se guardan los datos del negocio?

Hub Cloud guarda la base de datos del negocio en el entorno Cloud administrado por ERPlora.

### ¿Cómo informo de un problema?

Abre [Soporte](/support/) e incluye:

- El Hub y la página donde ocurrió el problema.
- La acción que estabas realizando.
- El mensaje de error exacto.
- El dispositivo, navegador o versión de la aplicación.
- Si el problema afecta a un usuario o a todos.

Nunca incluyas contraseñas, PIN, códigos de recuperación ni claves privadas de firma en un mensaje de soporte.
