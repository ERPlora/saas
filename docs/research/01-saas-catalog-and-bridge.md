## Login → elegir hub → entrar (hoy)
- `post_login_router` (`apps/auth/users/postlogin.py`), orden: view_mode advanced → dashboard; invitación pendiente → `/invitation/`; 0 hubs → `/start/`; 1 hub → `/enter/<id>/`; N con `Profile.last_hub` → enter(last); N sin memoria → `/businesses/`. `?next=` salta el router.
- `/start/` (`hubs/main/start.py`): GET con hub activo → `redirect_into_hub` con código; GET con hub preparando/dormido → página de progreso (`start_poll` htmx, `wake_free_hub`); GET sin hub → formulario (nombre obligatorio, país sugerido por Accept-Language, tipo de negocio opcional); POST → `provision_free_hub(user, name, slug=derive_start_slug(name), country, business_type)`; nombres duplicados → sufijo numérico.
- `/enter/<hub_id>/` (`hub_enter`): comprueba membresía, guarda last_hub, entra con código o vuelve a /start.
- `/businesses/` (`business_selector.py`): tarjeta por membresía con rol, último usado primero; 0 → /start; 1 → enter salvo `?choose=1`. Nunca muestra "hub" ni "organization".
- `/invitation/` (`invitation_accept.py`): lista pendientes; POST hub_id marca accepted_at y entra.
- `/shell/`, `/shell/open/<id>/`, `/shell/create/` (views.py:5011–5142): para apps nativas; `shell_open` → `redirect_into_hub(capture_marker=True)` añade `?shell=1`.
- Servicios free (`services/lifecycle.py`): `create_hub` (pending_payment, HubMember owner), `activate_free_hub` (Subscription active sin Stripe, deploying), `free_hub_quota_exceeded` (FREE_HUBS_PER_ACCOUNT=1), `provision_free_hub` idempotente, `wake_free_hub` (dormido tras 60 días).
- `AuthExchangeCode` (`apps/auth/users/models.py:176`): code token_urlsafe(32), user, expires_at (120 s), used_at, audience (hub-shell | session-exchange | browser-handoff | two-factor-login), destination_hub_id, password_fingerprint. `redeem()` con select_for_update, un solo uso. hub-shell: `hub_handoff.hub_entry_url()` → `{access_url}/#courier=<code>`; el hub lo canjea en `POST /api/v1/hub/device/session-courier/` con credencial de máquina → JWT con claims email + hubs[{id, org, role}] + user.
- `is_allowed_callback_url` (`oauth_redirect.py:166`): https a loopback, PARENT_DOMAIN, hosts permitidos o hubs del usuario.

## Miembros, invitaciones, traspaso, planes
- `HubMember` (`hubs/main/models.py:1476`): hub, user, role (owner|admin|member; legacy manager/employee → member), joined_at, accepted_at (null = invitación pendiente; no bloquea acceso). Unique(hub,user).
- `invite_user_to_hub` (`services/members.py:435`): `assert_hub_has_a_free_seat` → `user_limit_reached`; cap = `plan.max_users` (0 ilimitado); seats usados = max(HubMember count, Hub.reported_active_users).
- `HubOwnershipTransfer` (models.py:1576): from_user, to_user, status pending/accepted/declined/cancelled/expired, 7 días; al aceptar: viejo owner → admin; billing_profile no se mueve.
- `Plan` (`hubs/subscriptions/models.py:58`): max_users, max_devices (0 ilimitado), max_hubs_per_org, max_database_size_gb, includes_custom_domain, price_monthly, included_level. Free seed: 0 €, 1 hub, max_devices=1, max_users=3, sin dominio.
- `Hub` (models.py:155): id uuid, slug, name, address, country, business_type, billing_profile (null en free), subdomain, server, database_name (`hub_<hex12>`), deployment_status (pending_payment|deploying|active|stopped|suspended|error), deployment_url, is_active, is_demo, last_heartbeat, last_activity_at, free_inactivity_warned_at, free_inactive_since, suspended_at, deletion_requested_at, reported_active_users, machine_token_active. `HubCustomDomain` aparte. `access_url`: dominio propio → deployment_url → host del server → `<slug>.PARENT_DOMAIN`.
- `BillingProfile` (models.py:66): owner, billing_name, tax_id, billing_address/city/postal_code/country, billing_email, uk_*, stripe_customer_id.
- Cabeceras hub→SaaS (`permissions.py:23–36`): `X-Hub-Id` siempre; usuario: `Authorization: Bearer <JWT>`; máquina: `X-Api-Key erpk_live_…` (ApiKey: prefix, key_hash, hub, scopes, expires_at, revoked_at) o `X-Hub-Token` legacy o `X-Hub-Access-Token` (JWT 1 h). Interno: `X-Webhook-Secret` + `X-Hub-Id`.
